
# Factorial Calculator in C 🧮

A simple and efficient command-line program written in the **C programming language** to calculate the factorial of a given non-negative integer.

## 📌 Features
- Takes an integer input from the user.
- Calculates the factorial accurately.
- Handles edge cases (such as `0! = 1` and negative numbers).

## 🛠️ How to Run
1. Clone this repository or download the `.c` file:
   ```bash
   git clone https://github.com
   ```
2. Compile the C code using a compiler like `gcc`:
   ```bash
   gcc factorial.c -o factorial
   ```
3. Run the executable:
   ```bash
   ./factorial
   ```

## 💻 Example Output
```text
Enter a positive integer: 5
Factorial of 5 = 120
```
